# Weather Dashboard

A responsive weather dashboard built with HTML, CSS, and JavaScript using the OpenWeather API.

## Features

- Search weather by city
- Current temperature and weather condition
- Feels-like temperature
- Humidity
- Wind speed
- Atmospheric pressure
- Weather icons
- Hourly forecast
- Daily forecast
- Responsive design
- Error handling for invalid cities

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## What I Learned

- Working with REST APIs
- Fetch API and async/await
- Promises and error handling
- JSON data
- DOM manipulation
- Array methods such as `forEach()` and `map()`
- Working with timestamps and dates
- Dynamically generating HTML elements
- Responsive CSS

## How to Run

1. Clone the repository
2. Add your OpenWeather API key
3. Open `index.html` in a browser
